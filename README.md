## Инструкция по запуску проекта

1. **Клонируйте репозиторий**
2. **Создайте виртуальное окружение:**
   ```bash
   python -m venv venv
   venv\Scripts\activate

3. **В случае ошибки powershell используйте Command Prompt (cmd) или следующую команду: Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned**

4. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
5. **Откройте pgAdmin и создайте новую базу данных с именем audio_db.**
6. **Выделите созданную базу, нажмите правой кнопкой мыши -> Query Tool.**
7. **Откройте файл src/db/database.sql из проекта, скопируйте его содержимое в Query Tool и нажмите Execute. Это создаст все таблицы и загрузит данные.**
8. **Откройте файл database.py.**
9. **Найдите строку с настройками подключения (в методе __init__): host="localhost", port=5432, database="audio_db", user="postgres", password="123"**
10. **Если пароль от вашего пользователя postgres отличается от 123, измените его на свой.**
11. **Запустите main.py через команду (python main.py)**

## Тестовые аккаунты (Логины для входа)
Вход в систему осуществляется только по логину.
* **Администратор:** `admin`
* **Менеджер:** `manager1` или `manager2`
* **Клиент:** `client01` или любой другой из БД
* **Гость:** кнопка «Войти как гость», доступен только просмотр каталога
