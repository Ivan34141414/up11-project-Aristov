## 2. Обоснование сопоставления

*(На основе файлов проекта «Мир аудиотехники»)*

| Требование | Почему эти файлы |
| :--- | :--- |
| **А** | Чтобы узнать актуальное количество, нужны сами товары (1), их варианты (2) и таблица остатков (3). |
| **Б** | Изображение модели хранится прямо в карточке товара — в файле 1 есть колонка «Изображение» (например, IMG_19_001.png). |
| **В** | Для выбора нужны модели (1), их доступные варианты (2) и проверка наличия на складе (3). |
| **Г** | Дата заказа и ФИО клиента лежат в файле заказов (4). На скриншоте Orders_import.xlsx явно видны колонки «Дата заказа» и «ФИО». |
| **Д** | Управление заказами требует доступа к заказам (4) и привязки к конкретному пользователю (5). В файле Users_import.xlsx хранятся логины и роли (администратор, менеджер), которые управляют заказами. |
