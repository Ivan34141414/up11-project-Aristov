# Итоговый обзор проекта (Подготовка к Мини-ДЭ)
**Тема:** Разработка базы данных и приложения «Мир аудиотехники» для автоматизации продаж.

## 1. Анализ предметной области
В ходе анализа выделено **8 сущностей**:
1. `categories` — справочник категорий товаров.
2. `variants` — справочник вариантов исполнения (цвет корпуса).
3. `products` — модели аудиотехники (наушники, колонки и т.д.).
4. `stock_items` — остатки товаров на складе по вариантам.
5. `roles` — роли пользователей (админ, менеджер, клиент).
6. `users` — пользователи системы.
7. `orders` — заголовки заказов клиентов.
8. `order_items` — состав заказов (позиции).

## 2. Нормализация (3НФ)
Структура базы данных приведена к Третьей нормальной форме:
- **1НФ:** Все значения атомарны (ФИО разбито на отдельные поля, нет списков в ячейках).
- **2НФ:** Все неключевые поля зависят от полного первичного ключа (устранены частичные зависимости).
- **3НФ:** Устранены транзитивные зависимости. Справочники (категории, варианты, роли) вынесены в отдельные таблицы, чтобы не дублировать текст в основной таблице товаров и заказов.

## 3. Структура БД (ER-диаграмма)
- Построена в Draw.io.
- Все таблицы связаны внешними ключами (FOREIGN KEY).
- Связи: `categories → products` (1:N), `products → stock_items` (1:N), `variants → stock_items` (1:N), `users → orders` (1:N), `orders → order_items` (1:N).
- Экспортирована в PDF (`ERD_mir_audio.pdf`).

## 4. SQL-скрипт
Написан полный скрипт развертывания базы данных (`audio_db.sql`), включающий:
- Создание всех 8 таблиц с ограничениями (`PRIMARY KEY`, `FOREIGN KEY`, `CHECK`, `NOT NULL`, `UNIQUE`).
- Базовые `INSERT` запросы для наполнения справочников и тестовыми данными.

## 5. Импорт данных и проверка
- Выполнен импорт данных из файлов Excel заказчика (`Products_import`, `Variants_import`, `Orders_import` и др.).
- Проведена проверка через `SELECT COUNT(*)`: количество строк в БД полностью совпадает с исходными файлами (31 товар, 93 остатка, 20 пользователей, 15 заказов, 30 строк состава).
- Проверены связи (FOREIGN KEY) на отсутствие «битых» ссылок (результат: 0 ошибок).
