## 1. Создание таблиц и PRIMARY KEY (PK)
Для создания структуры БД использовалась команда `CREATE TABLE`. 
Каждая таблица имеет свой уникальный идентификатор (первичный ключ), который создается с помощью типа данных `SERIAL` и ограничения `PRIMARY KEY`. Это гарантирует уникальность строк и запрещает пустые значения (NULL).

*Пример (таблица категорий):*
```sql
CREATE TABLE categories (
    category_id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL UNIQUE
);
