# ДЗ 19: Повторение (Подготовка к Мини-ДЭ)

**Тема проекта:** Мир аудиотехники

## 1. Результаты повторения:
- **Анализ:** выделено 8 сущностей (categories, products, variants, stock_items, users, roles, orders, order_items).
- **Атрибуты:** все поля определены с правильными типами данных и ограничениями (PK, FK, CHECK, NOT NULL).
- **ЗНФ:** структура БД нормализована до 3НФ, транзитивных зависимостей нет.
- **ER-диаграмма:** построена в Draw.io, экспортирована в PDF (`ERD_mir_audio.pdf`).
- **Структура БД:** создана в PostgreSQL, все связи (FK) работают.
- **Скрипт БД:** написан скрипт `CREATE + INSERT` для полного развертывания базы.
- **Импорт:** данные из Excel файлов заказчика успешно импортированы.
