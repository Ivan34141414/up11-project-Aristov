# Сопоставление требований и файлов (Пара 14)

## Часть 1. Стандартное задание (Чудо Обувь)

### Сопоставление
**Ответ:** А-1,2,3; Б-1; В-1,2,3; Г-4,5; Д-4,5

### Обоснование
| Требование | Почему эти файлы |
| :--- | :--- |
| **А** | Чтобы узнать количество (остатки), нужны сами товары (1), их размеры (2) и таблица остатков (3). |
| **Б** | Изображение хранится в файле товаров (1) в колонке «Изображение». |
| **В** | Для выбора нужны модели (1), доступные размеры (2) и проверка, что они есть в наличии (3). |
| **Г** | Дата заказа есть в файле заказов (4), а ФИО клиента — в файле пользователей (5). |
| **Д** | Управление заказами требует данных о заказах (4) и о том, кто их оформляет (5). |

## Часть 2. Самостоятельная работа (Мир аудиотехники)

**Тема:** Мир аудиотехники — автоматизация продаж

### Сопоставление
**Ответ:** A-1,2,3; Б-1; В-1,2,3; Г-4,5; Д-4,5

### Обоснование
| Требование | Почему эти файлы |
| :--- | :--- |
| **A** | Для подсчета остатков нужны товары (1), их варианты (2) и сами остатки (3). |
| **Б** | Изображение — это атрибут товара, он находится в файле (1). |
| **В** | Чтобы выбрать товар, нужны модели (1), варианты (2) и проверка остатков (3). |
| **Г** | Дата берется из заказов (4), ФИО — из пользователей (5). |
| **Д** | Управление заказами — это работа с заказами (4) и пользователями (5). |
